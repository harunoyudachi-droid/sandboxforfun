# Простой калькулятор

Калькулятор для терминала на JavaScript, без внешних зависимостей.

## Запуск

Установите Node.js 22 или новее и выполните в папке проекта:

```sh
node calculator.js
```

Введите первое число, операцию (`+`, `-`, `*`, `/`) и второе число.
Например, `12.5`, `*`, `2` дадут `25`.
Десятичный разделитель — точка или запятая. Отрицательные числа поддерживаются.
Пустой ввод, неверная операция, деление на ноль и переполнение возвращают ошибку.

Калькулятор использует стандартную арифметику JavaScript с плавающей точкой:
для некоторых десятичных дробей возможна погрешность округления.
