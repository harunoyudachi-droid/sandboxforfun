# Инженерный калькулятор — Windows и Android

## Настольная версия

Для Windows 10/11 x64 добавлено нативное приложение с инженерными функциями, вводом с клавиатуры, панелью истории и копированием результата.

**Скачать EXE:** Actions → Windows Desktop → успешный запуск → Artifacts → `engineering-calculator-windows-x64`. Распакуйте ZIP и запустите `EngineeringCalculator.exe`; отдельная установка .NET не требуется.

[Инструкция и сборка Windows](desktop/README.md). Исходники находятся в `desktop/`.

# Инженерный калькулятор для Android

Нативное приложение на Java для Android 6.0+ (API 23). Работает офлайн, без рекламы, сетевых разрешений и внешних библиотек в самом приложении.

## Возможности

- Выражения со скобками, `+`, `−`, `×`, `÷`, степенями и унарным минусом.
- `sin`, `cos`, `tan`, `asin`, `acos`, `atan`; переключатель **DEG / RAD**.
- Корень `sqrt`, `ln`, десятичный `log`, `abs`, `exp`, факториал `!`.
- Константы `π`, `e`, последний успешный ответ `Ans`.
- История последних 20 вычислений: нажатие восстанавливает выражение и режим углов.
- Редактирование курсором и выделением, сохранение состояния при повороте и перезапуске.
- Прокрутка для небольших экранов и альбомной ориентации; отступы системных панелей.

Кнопки функций вставляют открывающую скобку; закрывайте её кнопкой `)`.
`±` меняет знак всего введённого выражения. После `=` выражение остаётся доступным для редактирования; для нового используйте `AC`, для предыдущего ответа — `Ans`.

## Как получить APK

В GitHub откройте **Actions → Android APK → успешный запуск → Artifacts → engineering-calculator-debug**.
Скачайте ZIP, распакуйте `app-debug.apk` и откройте на Android. Для скачивания артефактов нужен вход в GitHub. Сборки запускаются при изменениях в `main` и в pull request, а также вручную через **Run workflow** после попадания workflow в `main`.

Это отладочный APK для личной установки. Для Google Play нужна отдельная release-сборка и собственный ключ подписи.

## Сборка

Откройте корень проекта в Android Studio, установите SDK 35 и выберите JDK 17 для Gradle.
Проект использует Android Gradle Plugin 8.9.2 и Gradle 8.11.1. Gradle Wrapper не включён; для командной строки установите Gradle 8.11.1:

```sh
gradle testDebugUnitTest lintDebug assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.
CI выполняет те же проверки и сохраняет отчёты отдельным артефактом `android-reports`.

Совместимость инструментов: [Android Gradle Plugin 8.9](https://developer.android.com/build/releases/agp-8-9-0-release-notes).

## Правила вычислений

- `2+3*4 = 14`, `2^3^2 = 512`, `-2^2 = -4`, `2^-2 = 0.25`.
- `%` всегда делит число на 100: `200*10% = 20`, `100+10% = 100.1`.
- Умножение обязательно явно: `2*π`, `2*(3+4)`.
- Десятичный разделитель — точка или запятая. Кнопка `E` вводит экспоненту: `1.5E3 = 1500`.
- Факториал — для целых чисел от 0 до 170. Вычисления — в действительных числах.
- Деление на ноль, недопустимые аргументы, переполнение и неверный синтаксис показывают ошибку.
- Используется `double`; вывод округляется до 12 значащих цифр. `Ans` хранит полную точность.
- Ограничения: 512 символов и 64 уровня вложенности.

## Исходная версия

Простой калькулятор для Node.js сохранён в `calculator.js`; запуск: `node calculator.js`.
