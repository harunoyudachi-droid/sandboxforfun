# Fate — проверки подходов

Простое офлайн-приложение для Windows 10/11 x64. Шесть подходов: **Аккуратный, Умный, Эффектный, Силовой, Быстрый, Тайный**.

## Запуск

В GitHub: **Actions → Fate Windows → успешная сборка → Artifacts → fate-windows-x64**. Для скачивания нужен вход в GitHub.
Распакуйте ZIP и запустите `FateDice.exe`. Установщик и отдельная установка .NET не нужны.

## Проверка

1. Введите целочисленный модификатор в нужной строке (можно отрицательный).
2. Нажмите **Бросить** напротив подхода.
3. Приложение покажет четыре кубика и итог проверки.

Каждый кубик независимо выбирает одну из шести равновероятных граней: **+, +, −, −, пусто, пусто**.
Плюс даёт `+1`, минус `−1`, пустая грань `0`.

**Итог = модификатор выбранного подхода + сумма четырёх кубиков.**

Например: модификатор `+2`, кубики `[+] [−] [ ] [+]` → сумма кубиков `+1`, итог `+3`.

До броска кубики обозначены `?`, результат — `—`. После изменения модификатора прежний бросок этой строки очищается. Повторное нажатие бросает новые четыре кубика. Остальные строки сохраняют свои результаты.

Модификаторы сохраняются между запусками в `%LOCALAPPDATA%\SandboxForFun\FateDice\modifiers.json`. Результаты бросков не сохраняются. Диапазон модификатора — целое 32-разрядное число; итог считается в 64-разрядном типе, чтобы исключить переполнение.

## Разработка и проверка

Отдельное приложение в папке `fate/`; калькуляторы Windows и Android остаются в своих папках.
Нужен .NET SDK 10, сборка интерфейса — в Windows:

```powershell
dotnet run --project fate/Tests/Fate.Tests.csproj -c Release
dotnet run --project fate/Windows/FateDice.csproj
dotnet publish fate/Windows/FateDice.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:DebugType=None -o fate/publish
```

Тесты перебирают все 1296 исходов четырёх шестигранных кубиков, проверяют суммы, распределение граней, отрицательные модификаторы, крайние значения и сохранение настроек.
CI запускает собранный EXE и проверяет все шесть кнопок, ввод модификаторов, показ пустой грани, итоги и повторный бросок. Скриншоты и отчёт — в артефакте `fate-test-reports`.

Случайные грани получаются через [RandomNumberGenerator.GetInt32(6)](https://learn.microsoft.com/en-us/dotnet/api/system.security.cryptography.randomnumbergenerator.getint32?view=net-10.0), возвращающий значения от 0 до 5.
