# Инженерный калькулятор для Windows

Нативное приложение Windows Forms на C# / .NET 10. Офлайн, без рекламы и сетевых запросов.

## Запуск

Поддерживается 64-разрядная Windows 10/11. В GitHub откройте **Actions → Windows Desktop → успешная сборка → Artifacts → engineering-calculator-windows-x64**. Для скачивания нужен вход в GitHub.

Распакуйте ZIP и запустите `EngineeringCalculator.exe`. Это переносимая сборка: установщик, Node.js, Java и отдельная установка .NET не нужны. Подпись издателя в этой сборке отсутствует.

## Использование

- Выражение можно печатать на клавиатуре, вставлять и редактировать с выделением либо набирать кнопками.
- `Enter` — вычислить; `Esc` / `Ctrl+L` — очистить; `F2` — DEG/RAD; `Ctrl+Shift+C` — скопировать последний успешный ответ.
- Двойной щелчок по истории (или Enter в списке) возвращает выражение, режим углов и значение `Ans`.
- История последних 20 операций и текущий ввод сохраняются в `%LOCALAPPDATA%\SandboxForFun\EngineeringCalculator\state.json`.
- При ошибке вычисления последний успешный `Ans` сохраняется. Копирование берёт последний успешный результат.
- Кнопки функций вставляют открывающую скобку. Закрывайте её кнопкой `)`.
- `±` меняет знак всего выражения. После `=` можно редактировать прежнее выражение; для новой операции используйте `AC` или `Ans`.

Инженерные функции: `sin`, `cos`, `tan`, `asin`, `acos`, `atan`, `sqrt`, `ln`, `log`, `abs`, `exp`, степени, факториал, `π`, `e`, `Ans`.

Правила совпадают с Android: `-2^2 = -4`, `2^3^2 = 512`, `%` делит на 100 (`100+10% = 100.1`). Умножение вводится явно: `2*π`. Точка и запятая — десятичные разделители. `E` — экспонента числа (`1.5E3`). Факториал определён для целых 0…170.

Вычисления используют `double`; вывод — до 12 значащих цифр, `Ans` сохраняет полную точность. Ограничения: 512 символов и 64 уровня вложенности. Поддерживаются действительные числа.

## Разработка

Установите .NET SDK 10. Сборку приложения выполняйте в Windows:

```powershell
dotnet run --project desktop/Tests/Calculator.Tests.csproj -c Release
dotnet run --project desktop/Windows/EngineeringCalculator.csproj
dotnet publish desktop/Windows/EngineeringCalculator.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:DebugType=None -o desktop/publish
```

Структура: `Core` — разбор выражений, сессия и сохранение; `Windows` — интерфейс; `Tests` — проверки ядра без сторонних тестовых пакетов.
GitHub Actions запускает проверки ядра, собирает EXE и запускает его с проверкой кнопок, DEG/RAD, истории, ошибок и редактирования. Скриншоты обычного и минимального окна сохраняются в `desktop-test-reports`.

Параметр `--smoke-test <папка>` запускает встроенную проверку интерфейса, пишет отчёт и закрывает приложение, не затрагивая пользовательскую историю.

Принцип упаковки: [автономная сборка в одном файле .NET](https://learn.microsoft.com/en-us/dotnet/core/deploying/single-file/).
